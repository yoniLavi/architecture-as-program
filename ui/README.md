# Graph inspector

A visual **inspector** for the signal-graph demonstrator: it renders the
canonical graphs, triggers real execution on both enforcement tiers, and
overlays the resulting traces. It views and runs graphs; it does **not**
author them — graph authoring from the UI is an open research-agenda item.

What it demonstrates, and how honestly it must say so, is governed by the
`graph-inspector` spec (`openspec/specs/` after archive): everything the paper
asserts about this UI maps to a Python contract test
(`tests/test_poc_inspector_api.py`) or an e2e check (`e2e/inspector.spec.ts`).

## Design constraints (the ones that matter)

- **Pure consumer.** The graph view renders `graphs/*.json` served
  byte-for-byte by the execution API; traces are rendered exactly as returned.
  No graph model lives in TypeScript beyond parsing for display, and no fact is
  annotated UI-side — if the UI needs something, the fix is upstream (graph
  schema or trace schema).
- **No second execution engine.** Runs happen server-side in the existing `poc`
  runtime (`poc/inspector_api.py`, a stdlib HTTP layer over `assemble`/
  `execute`); WASM components run under the server's wasmtime, never in the
  browser. The API is read-and-run only.
- **Toolchain isolation.** Node lives only here (own lockfile). `make build`
  and the pre-commit hooks never touch it; the paper's inspector figures are
  the committed `screenshots/*.png`, regenerated by the e2e run.

## Running

```sh
make ui          # from the repo root: execution API + Next.js dev server
# or by hand:
uv run --group poc python -m poc.inspector_api   # API on :8123
npm run dev                                      # UI on :3000, proxies /api
```

Without wasmtime (`uv sync --group poc`) the API still serves host-tier runs;
the UI reports the confined tier as unavailable.

## Checks

```sh
npm run typecheck   # tsc
npm run build       # production build
npm run e2e         # Playwright: the paper-facing claims + screenshot regen
```

The e2e suite (`make ui-e2e`) starts both servers itself, asserts each
behaviour the paper reports (canonical rendering, run→trace, rejection with
reason class, sub-graph nesting with identity routing, taint visibility, tier
contrast), and rewrites `screenshots/` — which are committed, so the paper's
figures regenerate from the artifact instead of being pasted.
