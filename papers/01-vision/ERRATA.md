# Errata — Paper 1 (The Founding Vision)

This paper is **frozen**. Its source (`proposal.typ`) and its pinned inputs
(`graphs/`, `diagrams/`) reproduce the repository's state at commit `59898cc~1`
— the last state before the executable runtime demonstrator (`poc/`) was
introduced. The document dates itself *June 2026*, and that date is faithful:
the version genuinely existed in that form. A build check
(`scripts/check-freeze.py`) guards the source against silent edits.

Because it is a historical artifact, the text is **never rewritten in place**.
Corrections are recorded here instead, each dated, so the original claims and any
later corrections both remain legible. If you need to know what the founding
vision actually said, read `proposal.typ`; if you need to know what was later
found to be wrong with it, read this file.

For everything the demonstrator went on to substantiate, revise, or complicate,
see Paper 2 (`papers/02-demonstrator/`) and the change history under
`openspec/changes/`.
